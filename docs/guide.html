Read completeness before conclusions

A practical guide to missing values, numeric inference, and filtered summaries.

1. Distinguish missing from zero

Null and empty or whitespace-only text are missing. Zero and false are not. Completeness is the share of nonmissing cells across all columns in the currently filtered records. It is not an accuracy score.

2. Read numeric and mixed columns carefully

Finite numbers and decimal or exponent numeric strings count as numeric. Booleans, hexadecimal text, NaN, Infinity and ordinary text do not. Statistics use valid numeric cells only, so a mixed column's numeric mean is not a summary of every row.

3. Understand what the statistics mean

Mean, median, minimum, maximum and population standard deviation are computed on filtered records. A dash means a statistical value is missing or unrepresentable. Numeric summaries do not establish causation, remove outliers, or validate collection methods.

4. Treat a filter as a change in scope

Search matches a case-insensitive substring anywhere in a row. Counts, summaries and exports cover every match, while the preview shows only the first 20. Reset the filter before comparing with the full dataset.

5. Choose the right handoff

The contextual Visualize filtered data link replaces the shared ASF workspace with the matched rows. Normal navigation to Visualizer keeps the saved workspace instead. Your original file is never edited. Export filtered CSV or summary JSON when you need a local copy.

Try it with synthetic data

  1. Open Analytics and choose Use sample data.
  2. Check that visitors has one missing value.
  3. Search for Aug, compare completeness, then reset.
  4. Use a filter with no matches and confirm that Visualize filtered data cannot replace the workspace with an empty dataset.

Data is processed locally. Shared-origin session storage is not a secure boundary; avoid sensitive information and clear the workspace when finished. Use Discovery for a transparent starting-point assessment, not a guarantee.
